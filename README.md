# 🏡 Airbnb  
### A Full-Stack Airbnb-Inspired Accommodation Booking Platform

---

## 📌 Overview

**StayNest** is a full-stack web application inspired by Airbnb that allows users to explore, create, and manage property listings.  
It focuses on real-world backend concepts such as authentication, session management, database relationships, file uploads, and deployment.

This project was built as a learning-oriented but production-structured application.

---

## 🚀 Features

- 🔐 User Authentication (Sign up / Login / Logout)
- 🏠 Create, Edit, and Delete Property Listings
- 📸 Image Uploads using Cloudinary
- 🗂️ MongoDB Database with Mongoose
- 🛡️ Secure Sessions with Passport.js
- 🎨 Server-Side Rendering using EJS
- 📱 Responsive UI using Bootstrap
- ☁️ Deployed on Render
